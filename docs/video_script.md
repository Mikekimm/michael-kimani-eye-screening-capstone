# Walkthrough video script (about 12 minutes)

Record the screen at 1080p with your voice. Never show a real patient photo or your `.env` file.

## Before recording

1. Start the backend and frontend (README section 7) and run `scripts/seed.py` once.
2. Sign in once as each demo account so the consent screen is already accepted.
3. Have ready: 2-3 **public dataset** fundus photos (one with DR, one without), one blank image.
4. Use two browser windows (or one normal and one private) so the stranger and the admin are side by side.

## Demo credentials (synthetic demo data only)

| Role | Email | Password |
|---|---|---|
| Admin | `admin@example.org` | value of `SEED_ADMIN_PASSWORD` in your local `.env` |
| Specialist | `specialist@example.org` | value of `SEED_SPECIALIST_PASSWORD` |
| Health worker (approved) | `nurse@example.org` | value of `SEED_HEALTH_WORKER_PASSWORD` |
| Facilities | Demo Health Centre A, Demo Health Centre B, Demo District Hospital | created by `scripts/seed.py` |

The passwords are generated by `scripts/init_env.py` and live only in `.env`, which is never committed,
so they are not written here. Look them up with `Select-String SEED_ .env` before recording, and never
reuse them on a hosted deployment.
